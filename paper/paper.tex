\begin{abstract}
I train a small PyTorch convolutional network on 8 by 8 handwritten digit images. The model uses two convolution and pooling stages before a ten-class output layer.
\end{abstract}

\section{Question}
Can a compact CNN use the spatial structure of the digit images effectively?

\section{Data and Method}
I use a stratified 75/25 split of the scikit-learn digits dataset. Pixels are divided by 16 and reshaped to 1 by 8 by 8 tensors. The network uses 16 and then 32 convolutional channels, max pooling, and a final 128-to-10 linear layer.

\section{Training}
Training uses batch size 64, Adam with learning rate 0.003, cross-entropy loss, and 14 epochs.

\section{Results}
The recorded run reaches 0.9600 accuracy and 0.9597 macro-F1.

\section{Limitations}
The dataset is small and clean. Small numerical differences can also appear across PyTorch and CPU-library versions even when the random seed is fixed.

\section{Reproduction}
Install \texttt{requirements.txt} and run \texttt{python src/run\_experiment.py}.
